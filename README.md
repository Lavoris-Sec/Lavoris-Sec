# Lavoris-Sec

### Информационная безопасность · Embedded · Разработка

Изучаю технические средства защиты информации и разрабатываю
программные и аппаратные проекты: от микроконтроллеров и IoT
до автоматизации и работы с нейросетями.

## Чем занимаюсь

- **Информационная безопасность:** исследование технических средств
  защиты и разработка проектов в области ИБ.
- **Embedded и IoT:** проекты на ESP32, Raspberry Pi Pico и Arduino;
  работа с периферией и камерой ESP32-S3.
- **Разработка ПО:** приложения и утилиты на Python и C++.
- **Нейросети и компьютерное зрение:** эксперименты с моделями
  и инструментами машинного обучения.

## Проекты и учебные материалы

### Разработка и информационная безопасность

- **microcontrollers** — проекты для микроконтроллеров.
- **SecureData_Suite** — курсовой проект по информационной безопасности.
- **utils** — небольшие утилиты.

### Искусственный интеллект

- **AI-Emotion-Recognition** — распознавание эмоций по лицу с помощью
  модели машинного обучения.
- **AI-Items-Detector** — проект по обнаружению объектов.

### Учёба

- **PH1826** — работы и задания, выполненные во время обучения на курсах.
- **seti** 🔒 — конспекты и технические паспорта лабораторных работ
  по компьютерным сетям. Приватный репозиторий.

### Другие проекты

- **translate-ru-quintessential-quintuplets-memories-summer** —
  проект перевода визуальной новеллы на русский язык.
